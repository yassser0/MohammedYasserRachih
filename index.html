Mohammed Yasser Rachih — Junior Data Engineer, Casablanca, Morocco

Mohammed Yasser Rachih is a Junior Data Engineer based in Casablanca, Morocco. He holds a Master's degree in Big Data and Data Science from Faculté des Sciences Ben M'Sick (FSBM), Casablanca. He specializes in building robust data pipelines and distributed big data architectures using Python, Apache Spark, PySpark, Databricks, Delta Lake, Apache Kafka, ETL/ELT workflows, SQL, PostgreSQL, and Docker.

Professional Experience

Data Engineering internship at Marsa Maroc (March – July 2026): designed and developed data solutions, ETL pipelines, data quality processes, and contributed to a port operations management platform. Development internship at Jisr (March – July 2024): designed and developed web application features.

Key Data Engineering Projects

Real-Time Data Engineering Platform — Apache Kafka and Spark Streaming

Distributed platform ingesting high-throughput event streams via Apache Kafka, processing with Spark Structured Streaming (micro-batches, windowed aggregations, dead-letter queue routing), persisting in PostgreSQL and Delta Lake, and monitoring via Streamlit and Grafana dashboards. Technologies: Apache Kafka, Apache Spark, PySpark, Structured Streaming, PostgreSQL, Delta Lake, Docker Compose, Grafana.

Production-Ready ETL Pipeline — Apache Airflow and dbt

End-to-end automated ETL pipeline extracting data from REST APIs and CSV files, orchestrated with idempotent Apache Airflow DAGs, transformed and quality-tested with dbt models, loaded into Snowflake and PostgreSQL data warehouses. Features automated error handling, retries, and Slack alerts. Technologies: Apache Airflow, dbt, Python, PostgreSQL, Snowflake, Docker, Pandas.

Enterprise Data Lakehouse — Databricks and Delta Lake

Enterprise Lakehouse platform implementing Medallion Architecture (Bronze raw ingestion, Silver cleaning and fraud detection, Gold business KPIs) on Databricks with ACID Delta Lake guarantees, centralized Unity Catalog governance, data lineage, and query optimization via Z-Ordering and Liquid Clustering. Technologies: Databricks, Apache Spark, Delta Lake, PySpark, Unity Catalog, SQL.

Morocco DataHub — Unified Moroccan Open Data API Platform

DataTech project centralizing and distributing Moroccan public datasets from official sources (HCP, data.gov.ma, Bank Al-Maghrib) through automated ETL pipelines, relational modeling in PostgreSQL, and secure OpenAPI-documented REST endpoints via FastAPI. Technologies: Python, FastAPI, PostgreSQL, ETL Pipelines, Data Quality, Docker, REST API.
